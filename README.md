# Pattern Output Tracker

面向英语、日语写作输出的 Obsidian Pattern 收集与命中原型。

## 0.7.0-alpha.3：翻译工作台产品化打磨

统一提升切材画布、翻译台、导入窗口、空状态和窄屏布局。长文切分会保持当前位置；当前单位按需进入视野；标题、进度和练习状态形成稳定的操作台层级。加入整理阶段撤销、重做、取消选择和开始翻译快捷键，以及翻译阶段的确认、上一项、下一项快捷键。练习菜单支持重命名、删除、打开来源和保留旧版本后重新整理。

## 0.7.0-alpha.2：原文切材画布

翻译练习的整理阶段改为连续原文画布。导入后保留基础排版，直接拖选原文即可切出学习单位；已切部分退灰，尚未处理的部分保持正文颜色。自动分割使用同一个切出模型，已经切出的单位可以放回原文重新切分，也可以合为一个单位。开始翻译后，同一张画布成为左侧原文导航，右侧展开逐单位翻译台。

## 0.7.0-alpha.1：翻译练习骨架

新增可运行的翻译练习工作台。可以从笔记选中文本创建练习，也可以在练习页面直接粘贴原文。开始前通过单位轨道拆分、合并和调整段落；多行可以合并为同一学习单位。开始翻译后原文结构锁定，左侧保留全文语境，右侧逐单位编辑、确认译文，进度自动保存到 `_PatternOutputTracker/translations.json`。

当前版本先验证“导入—整理单位—逐单位翻译—恢复进度”。片段关联、包裹语法、关系注释和对子列表将在这个工作台稳定后接入。

## 0.6.0-alpha.3.3.2：单一结构操作区

当前测试版正在重做 Pattern Maker。内容元素按 S／C／L 位置分组，位置使用加深的左右开放作用域；位置间关系弱化为无按钮外观的文字和短指示条，严格标点作为关系参数显示，例如“相邻（——）”。操作区现在是唯一、所见即所得的结构表达，不再重复显示“结构预览”。

句内分句入口在没有确认任何分句边界时会自动归一为普通句内 Pattern，并在操作区上方显示轻量提示。当前 alpha 只验证制作交互和结构表达，尚未把新版结构写入 Vault。

## 0.5.0：独立 Pattern Maker

选中笔记中的一段原文后，Pattern Maker 把这段文字作为临时工作区。先选择句法结构，再在画布中标记组成部分：

- **连续片段**：拖选一个连续范围。
- **断开组合**：依次拖选 A、B、C 等不连续成分。
- **句子序列**：点击完整句子，把它们组成有顺序的成分。
- **句组序列**：选择若干句子组成 A，再选择若干句子组成 B。

Maker 只负责结构制作。Pattern 的语言、Tag 和说明等资料由独立的轻量编辑窗口管理，两者不再混在同一个大表单中。

## 数据模型

- Pattern 的正式类型只描述句法／匹配结构。
- Idiom、搭配、术语、领域、修辞功能、语体和场景等语义分类全部交给普通 Pattern Tag。
- Pattern Tag 使用 `/` 表示层级，例如 `领域/经济学/金融`；允许 Pattern 不带 Tag。
- 数据保存在当前 Vault 的 `_PatternOutputTracker/` 中。

## 当前能力边界

- 四种结构可以制作、保存、重新打开和按组成部分识别。
- “语法等价”可以在成分上标记，但 0.5.0 的识别仍暂时按原文匹配；词形、时态等价将在之后接入。
- 句子和句组模式目前以完整句子为基本单位。
